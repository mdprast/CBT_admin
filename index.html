Buku Panduan Penggunaan Examify PDF & Native CBT

⚠️ KEBIJAKAN PENGHAPUSAN DATA 7 HARI

Untuk menjaga agar aplikasi tetap ringan dan stabil, sistem akan menghapus data nilai siswa secara otomatis dalam waktu 7 hari sejak jawaban dikirim.
Peringatan: Data yang sudah terhapus tidak dapat di-Undo (dikembalikan). Oleh karena itu, sangat diwajibkan bagi Guru untuk segera menekan tombol ⬇ Unduh Excel setelah ujian selesai dilaksanakan.

1. Format Pembuatan SOAL & Kunci Jawaban (Mode PDF & Mode Native CBT)

Anda dapat memilih **Mode Soal PDF** (mengunggah dokumen PDF) atau **Mode Native CBT** (menyusun soal interaktif satu per satu ala Google Form lengkap dengan gambar WebP, Wacana Soal Beranak, Acak Soal, dan Impor Excel).

Agar sistem dapat mengoreksi otomatis dengan akurat 100%, ikuti panduan pengisian kunci berikut berdasarkan tipe soal:

  • Pilihan Ganda Biasa & Benar/Salah (1 Pernyataan): Cukup klik opsi yang benar pada tombol yang disediakan.
  • B/S Kompleks (2 s.d 5 Pernyataan - Model TKA/AKM): Klik kunci B atau S pada setiap baris pernyataan secara berurutan. Siswa wajib menjawab seluruh pernyataan dengan urutan yang tepat.
  • Pilihan Ganda Kompleks: Klik 2 atau lebih opsi jawaban yang benar.
  • Menjodohkan: Ketikkan pasangan angka dan huruf. Anda boleh memisahkannya dengan koma atau spasi (Misal: 1A, 2B, 3C atau 1A 2B 3C). Sistem kami secara cerdas akan membersihkan dan mengurutkannya secara otomatis menjadi format 1A2B3C.
  • Isian Singkat: Ketik jawaban pasti (Sama Persis/Exact Match) tanpa embel-embel satuan. Misal jika jawaban adalah 50 cm, maka tulis kuncinya: 50. Berikan instruksi di naskah ujian agar siswa cukup menjawab angkanya saja tanpa mengetik satuan.
  • Uraian: Kosongkan saja. Sistem TIDAK menilai soal uraian secara otomatis. Anda wajib mengunduh rekap file Excel di akhir ujian untuk membaca hasil uraian dan memberi nilai manual.

2. Keamanan Anti-Hacker (Enkripsi Lapis Ganda)

Aplikasi ini dilengkapi Sistem Enkripsi 2 Lapis, sehingga siswa tidak dapat membuka soal sebelum waktunya.

  • Gembok Pertama (Kode Sinkronisasi / Token): Berikan kode ini kapan saja (misal H-1). Kode ini digunakan siswa untuk menyinkronkan (mengunduh) paket file dari Cloud ke HP mereka.
  • Gembok Kedua (PIN Pengawas): PIN ini HANYA boleh diucapkan secara lisan/ditulis di papan tulis oleh Pengawas ruangan tepat saat bel ujian berbunyi. Hanya dengan PIN inilah file soal terbuka dan ujian dimulai.

3. Tahap Pembuatan Soal & Kunci Jawaban

  • Klik tombol + Buat Ujian Baru di Beranda, lalu pilih tab Mode Soal PDF atau Mode Native CBT.
  • Isi identitas ujian, termasuk Kode Sinkronisasi (Token) dan PIN Pengawas.
  • Pada Mode Native CBT, Anda bisa menambahkan gambar yang otomatis dipotong (crop) dan dikompresi menjadi format WebP super ringan, atau mengimpor soal sekaligus menggunakan Template Excel.
  • Klik Buat File Ujian. Aplikasi akan membungkus seluruh soal dan gambar menjadi satu file tunggal (.enc) yang langsung terunduh ke perangkat Anda.

4. Distribusi Otomatis via Cloud Sync (Disarankan)

Agar siswa tidak repot mencari file di memori HP mereka, gunakan fitur Sinkronisasi Cloud. Berikut langkahnya:

  1. Buka Google Drive Anda, lalu klik Baru (New) -> Upload File. Pilih file .enc yang baru saja Anda buat.
  2. Setelah ter-upload, klik kanan pada file tersebut dan pilih Bagikan (Share).
  3. Pada bagian Akses Umum (General Access), ubah status menjadi "Siapa saja yang memiliki link" (Anyone with the link). Pastikan perannya adalah Pelihat (Viewer).
  4. Salin link tersebut, lalu kembali ke Beranda Portal Guru.
  5. Pada Kartu Ujian yang bersangkutan, tempel (paste) link tersebut ke kolom Link Google Drive dan klik Simpan.
  6. Selesai! Saat ujian, siswa cukup membuka tab "Sinkron Cloud", mengetikkan Kode Sinkronisasi (Token), dan soal akan otomatis terunduh ke HP mereka.

5. Distribusi Manual (Jika Cloud Sync Gagal)

Jika koneksi internet sekolah sangat buruk atau link Google Drive bermasalah, Anda tetap bisa mengirimkan file langsung (Offline-First):

  1. Kirimkan file .enc yang Anda unduh dari Portal Guru ke grup WhatsApp kelas atau via Flashdisk.
  2. Siswa mengunduh/menyimpan file tersebut ke HP mereka.
  3. Di aplikasi CBT Siswa, siswa membuka tab File Manual.
  4. Siswa menekan tombol Cari File di HP dan memilih file .enc tersebut.
  5. Siswa memasukkan Kode Sinkronisasi (Token) dan PIN Pengawas seperti biasa untuk memulai ujian.

6. Pengumpulan Ujian (Server)

  • Aplikasi siswa telah dilengkapi fitur Kirim Ulang Otomatis (Auto-Retry). Jika sinyal putus atau server penuh saat mengumpulkan, aplikasi akan mencoba mengirim ulang secara otomatis di latar belakang sebanyak 3x.
  • TIPS PENGAWAS: Hindari memberikan instruksi pengumpulan serentak dengan aba-aba hitung mundur (Misal: "Semuanya klik Selesai dalam 3, 2, 1!"). Hal ini dapat menyebabkan antrean data yang terlalu menumpuk. Biarkan siswa menekan tombol "Selesai" secara natural saat mereka sudah yakin.
  • Tidak ada jaminan aplikasi dan server selalu dalam keadaan lancar.
