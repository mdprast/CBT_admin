Buku Panduan Penggunaan Exam-CBT (PDF & Native CBT)

⚠️ KEBIJAKAN PENGHAPUSAN DATA 7 HARI

Untuk menjaga agar aplikasi tetap ringan dan stabil, sistem akan menghapus data nilai siswa secara otomatis dalam waktu 7 hari sejak jawaban dikirim.
Peringatan: Data yang sudah terhapus tidak dapat di-Undo (dikembalikan). Oleh karena itu, sangat diwajibkan bagi Guru untuk segera menekan tombol ⬇ Unduh Excel setelah ujian selesai dilaksanakan.

1. Format Pembuatan SOAL, Skor Parsial, Rumus Matematika & Paste Snipping Tool

Anda dapat memilih Mode Soal PDF (mengunggah dokumen PDF) atau Mode Native CBT (menyusun soal interaktif satu per satu lengkap dengan Equation Matematika, Gambar WebP, Wacana Soal Beranak, Acak Soal, dan Impor Excel).

  • Fitur Skor Parsial vs Eksak (Berlaku di Mode PDF & Native CBT): Untuk soal kompleks (PG Kompleks, B/S Kompleks, dan Menjodohkan), Anda dapat mencentang ⚖️ Skor Parsial agar siswa tetap mendapat nilai proporsional sesuai jumlah pernyataan/pasangan yang dijawab benar (dilengkapi penalti anti-tebak semua untuk PG Kompleks). Jika tidak dicentang (Mode Eksak), siswa wajib menjawab benar seluruh komponen untuk mendapatkan poin.
  • Menyisipkan Gambar Cepat dari Snipping Tool (Tanpa Simpan File): Ambil tangkapan layar gambar soal/opsi menggunakan Snipping Tool (Win + Shift + S), lalu klik langsung di dalam kotak teks Wacana, Pertanyaan Soal, atau Opsi Jawaban dan tekan Ctrl + V (atau klik tombol 📋).
  • Menyisipkan Rumus Matematika (Equation): Klik tombol ∑ yang tersedia di setiap kotak Pertanyaan Soal, Wacana, maupun Opsi Pilihan Jawaban.
  • Isian Singkat: Ketik jawaban pasti (Sama Persis/Exact Match) tanpa embel-embel satuan. Misal jika jawaban adalah 50 cm, maka tulis kuncinya: 50.
  • Uraian: Kosongkan saja. Sistem TIDAK menilai soal uraian secara otomatis. Anda wajib mengunduh rekap file Excel di akhir ujian untuk membaca hasil uraian dan memberi nilai manual.

2. Fitur Edit / Revisi Ujian & Limitasi Media

  • Jika terdapat kesalahan kunci jawaban, mode skor parsial, nomor halaman PDF, atau teks soal, klik tombol ✏️ Edit pada Kartu Ujian di Beranda.
  • Setiap penyimpanan revisi ujian akan mengunduh file .enc baru dan memotong 1 Kredit.
  • Unggah file .enc hasil revisi tersebut ke Google Drive / Cloud Anda, salin link barunya, lalu tempelkan menggantikan link lama pada Kartu Ujian di Beranda.

3. Keamanan Anti-Hacker (Enkripsi Lapis Ganda)

Aplikasi ini dilengkapi Sistem Enkripsi 2 Lapis, sehingga siswa tidak dapat membuka soal sebelum waktunya.

  • Gembok Pertama (Kode Sinkronisasi / Token): Berikan kode ini kapan saja (misal H-1). Kode ini digunakan siswa untuk menyinkronkan (mengunduh) paket file dari Cloud ke HP mereka.
  • Gembok Kedua (PIN Pengawas): PIN ini HANYA boleh diucapkan secara lisan/ditulis di papan tulis oleh Pengawas ruangan tepat saat bel ujian berbunyi. Hanya dengan PIN inilah file soal terbuka dan ujian dimulai.

4. Distribusi Otomatis via Cloud Sync (Disarankan)

  1. Unggah file .enc yang baru saja Anda buat ke Google Drive, GitHub, atau Supabase Storage.
  2. Pastikan akses file diatur menjadi publik / "Siapa saja yang memiliki link" (Anyone with the link).
  3. Pada Kartu Ujian di Beranda Portal Guru, tempel (paste) link tersebut dan klik Simpan Link.
  4. Saat ujian, siswa cukup membuka tab "Sinkron Cloud", mengetikkan Kode Sinkronisasi (Token), dan soal akan otomatis terunduh.
